EliteOps B2B Lead Intelligence Platform

Complete Operational Manual, Architecture Specification & API Key Guide

1. Executive Summary & Core Purpose

The EliteOps Lead Intelligence Platform is an enterprise B2B client acquisition system built specifically for EliteOps Global. It automates the discovery, auditing, scoring, and outreach pipeline for high-intent B2B clients across target regions: USA, Canada, United Kingdom, Australia, and UAE.

Target Business Profile: Insurance Agencies & Brokerages

The system specifically targets independent commercial insurance agencies, local brokerages, and risk consulting firms (20 to 100 employees). Unlike massive corporate carriers, independent insurance agencies actively contract external partners for Website Redesign (Next.js/React), Digital Marketing & Local SEO, Virtual Assistants, and Back-Office Support.

2. API Keys Configuration & Integration Guide

The platform leverages 5 core API keys configured in the environment file (.env). Each key performs a distinct role in discovering, enriching, and scoring real business prospects:

API Key Name Service Provider Primary Function & Use Case
OPENAI_API_KEY OpenAI (GPT-4o) Calculates multi-factor Opportunity Scores (0–100), synthesizes website audit reports, and generates 1-click human-sounding cold emails, follow-ups, LinkedIn hooks, and call scripts.
GOOGLE_SEARCH_API_KEY Google Custom Search Executes live web searches querying official business domains and registered agency websites across 50 US states & Canadian provinces.
GOOGLE_SEARCH_CX Google Programmable Search Engine Defines the search context and index boundaries, filtering out generic directories (Wikipedia, Yelp) to isolate real commercial agencies.
HUNTER_API_KEY Hunter.io API Enriches company domains with 100% deliverable corporate email addresses (support@, info@, marketing@) and verifies executive contact listings.
APOLLO_API_KEY Apollo.io API Enriches company firmographics including employee headcount, estimated annual revenue, founding year, corporate phone lines, and social links.
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY Google Places & Maps API Fetches real-time Google Maps location data, star ratings, review counts, and direct Google Maps navigation links for each business.

3. Live Scan Engine Architecture (/api/scan)

When a user clicks "Scan 100 NEW Google & Maps" or "Re-check & Verify Details", the following multi-step workflow executes:

  • Step 1: Cache Cleanup — The UI clears all existing cached records (setCompanies([])) to ensure only fresh data is presented.
  • Step 2: Live Domain Search — The backend queries Google Custom Search API for active agency domains in the selected region (e.g. Insurance Agencies in Idaho).
  • Step 3: Email & Firmographic Enrichment — Discovered domains are passed to Hunter.io & Apollo.io APIs to fetch deliverable corporate emails and revenue data.
  • Step 4: Zero 404 LinkedIn Sync — The system generates targeted LinkedIn Search URLs (https://www.linkedin.com/search/results/people/?keywords=...), ensuring 1-click LinkedIn buttons open valid searches without 404 errors.
  • Step 5: AI Scoring — OpenAI GPT-4o synthesizes the audit data into a multi-factor score (0–100).

4. Platform User Manual & Feature Guide

1. Full-Screen Command Center Layout

Use the Full Screen toggle button (Maximize2 icon) in the top header to enter native browser fullscreen. Click the Sidebar Toggle button (PanelLeft icon) to collapse the left panel for an edge-to-edge 100% monitor layout expansion up to 1920px width.

2. Key Decision Makers & 100% Deliverable Emails

Inside the company details modal, view verified executive contacts including Agency Principals, Agency Owners, and Marketing Managers. Each email displays a green 100% Deliverable badge to ensure cold outreach emails sent via Outlook or Gmail never bounce.

3. 1-Click Microsoft Excel Exporter

Click "Save in DB & Download Excel" to export prospect data into a UTF-8 BOM CSV file compatible with Microsoft Excel. The export includes separate dedicated columns for CEO/Founder Name, Title, Email, Phone, LinkedIn and Marketing Manager Name, Title, Email, Phone, LinkedIn.

4. Interactive CRM Kanban Pipeline

Track lead progress across 9 phases: NEW → RESEARCHING → CONTACTED → EMAIL_SENT → MEETING_SCHEDULED → PROPOSAL_SENT → NEGOTIATION → WON.

5. Environment & System Setup

To run the platform locally or deploy to production, execute the following commands:

# 1. Install Dependencies
npm install

# 2. Database Migration & ORM Code Generation
npx prisma db push

# 3. Launch Development Server
npm run dev
# Server running at http://localhost:3000

# 4. Launch Docker Production Stack
docker-compose up -d --build
